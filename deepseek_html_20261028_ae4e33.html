Wrong way to open this file

This file is a Node.js server

You opened it as an HTML page (file://). It's supposed to be run, not opened — the browser can't make network calls from file:// URLs.

Step 1

Open a terminal (Command Prompt / Terminal).

Step 2

Install Express once:

npm install express
Step 3

Run this file as a Node.js server:

node fund.js
Step 4

Open this URL in your browser — the correct URL, not file://:

http://localhost:3000/fund.html

If you meant to test the deposit panel only, you can also run python -m http.server 8000 in the same folder and open http://localhost:8000/fund.js — but the withdraw flow needs the Express server.
